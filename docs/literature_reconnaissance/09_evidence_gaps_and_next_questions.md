# 证据缺口与下一轮问题

## 目前还不能回答

1. **REV60 是否在真正新样本中成立。** 现有证据只是 MOM60 的符号翻转，Phase B 未开启。
2. **八类量价构造在 A 股宽基上究竟延续还是反转。** 文献支持条件性机制，不支持统一方向；本任务未运行任何检验。
3. **主题池的历史成员是否可 point-in-time 重建。** 当前概念成员如果只保留今日名单，会有成员回填和幸存偏差。
4. **56 只股票的有效横截面样本有多大。** 同主题、同行业和共同事件会让名义 56 远大于有效独立样本。
5. **项目的成交额、换手率和自由流通股本是否有完整历史口径。** 没有它们，异常量和容量研究会混入股本变化。
6. **涨跌停、停牌和 ST 的逐日历史是否齐全。** 没有可成交状态，收盘信号可能建立在无法实现的价格上。
7. **QFQ/HFQ 与点时收益目标的统一口径。** 因子计算可使用复权序列，但执行和涨跌停判断必须回到当时可见的原始价格/规则。
8. **LLM+MCTS 论文的同 bar 时序。** 当日 OHLC/VWAP 与按收盘成交之间是否有至少一日滞后，需要作者代码或补充说明。
9. **自动搜索基线是否获得完全相同预算。** 需要每种方法的候选回测数、参数尝试数、失败公式和 wall-clock/模型调用记录。
10. **Tier 2 自动挖掘论文能否独立复现。** AlphaAgent、Alpha-GPT 等摘要中的强结果尚未由本项目复现，不能据此授权搜索。

## 需要补充的证据

| 缺口 | 最小补充材料 | 为什么重要 |
|---|---|---|
| 历史主题成员 | 每个生效日的成员、加入/移除日期、来源版本 | 防止用今天的主题定义解释过去 |
| 交易状态 | 停牌、ST/*ST、上市/退市、板块、当日限制幅度 | 判断信号是否可成交 |
| 股本与换手 | point-in-time 自由流通股本或可靠换手率 | 跨期量能归一化 |
| 公司行动 | 除权除息、拆并股与复权因子版本 | 区分价格跳变与真实收益 |
| 事件时间 | 首次公开时间、来源 URL、盘中/盘后标签 | 确定事件日和可交易时点 |
| 搜索日志 | 每个候选公式、规范化式、参数、失败原因和预算 | 多重检验、PBO/DSR 与公平基线 |
| 开放全文 | 核心自动搜索论文的作者/机构版本 | 核验数据切分、成本和负面结果 |

## 在编码前需要导师/学生决定

1. 宽基 sandbox 的股票范围、历史起点和可用 point-in-time 数据源。
2. 下一批只研究一个量价主问题，还是先完善数据约束；不应两者同时扩张。
3. 一个候选家族最多允许多少窗口、阈值和方向。
4. 最终测试的日期范围、冻结时间和谁有权查看。
5. 成本、滑点、涨跌停不可成交和容量的统一规则。
6. 主题研究的目标是“主题暴露描述”还是“主题内横截面预测”；两者不能混用同一结论。

## 建议的停止条件

在以下条件满足前，不开启新因子实现：

- Must Read 八篇的读后问题已完成；
- point-in-time 股票池与交易状态的数据缺口已列清；
- 新假设只有一个主变量、一个方向、一个持有期；
- trial ledger 能记录失败和近重复；
- Phase B 和 MCTS 仍保持锁定，除非得到新的明确授权。

## 对后续全文获取的原则

- 优先作者主页、机构仓库、arXiv、ACL Anthology、NBER/SSRN 和开放期刊。
- 付费墙只使用正式摘要与元数据，不绕过访问控制。
- 获取全文后先更新 `full_text_status`，再补作者限制、页码与负面结果；不得用摘要推测正文细节。
